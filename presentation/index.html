Surprising facts

🤔 Humans hesitated — models didn't

  • On the 5 roofs that first split our labelers, models output confident calls
  • sv-0133: 2 humans said no_solar, Kimi said solar
  • Majority vote settled each dispute (4:1 or 3:2)

💚 Open-weights = honest about doubt

  • Gemma: 11/30 uncertain (most) · Kimi: 8/30 (above closed models)
  • Gemma is 10× cheaper than GPT-5.5 — the least over-confident

Why it matters: a scanner that is confident on exactly the roofs humans hesitate over is the failure a verification layer must catch

One approach that failed — and why

Failed: bare-prompt classification with the default setup

  • What we tried: first pass with Gemini 2.5 Flash models, plain "classify this roof" prompt, default parsing.
  • What failed: 2.5 models returned 404 for new accounts; one model emitted malformed/multi-object JSON; free-tier rate limits (429) stalled ~40 calls.
  • Evidence: result files with error rows; the retry/resume logic in evaluate_benchmark.py; the robust JSON extractor added after the parse failures.
  • Lesson: treat every model output as a candidate, verify the pipeline before trusting any number.

Second failure: models over-trust themselves

The scorecard itself caught it — confident solar/no_solar on roofs humans called uncertain. A confident wrong answer on an ambiguous roof is what a verification layer must prevent.

What looks promising

Structured contract + human escalation

  • ✅ Output contract works — 120 calls, all parseable JSON
  • ✅ Clear cases separable — models broadly agree on solar
  • ✅ Escalation path — catches the 60% of roofs where models disagree
  • ✅ Multi-source branch works — 20/20 rule-following with public records
  • 🔜 Next test — 100 roofs: does escalation recall rise & do manual reviews fall?

Recommendation: revise, then a limited test

What the evidence supports now

  • Not "stop", not "deploy as-is" — baseline 83% → 33% (Gemma) on hard roofs
  • Revise escalation behavior (prompt / threshold), then test on 100 roofs
  • Add multi-source corroboration — public NYC records (solar permits, building footprints) to catch confident wrong answers
  • Cost is not the blocker — $0.002–$0.013 per correct roof

Potential value

Manual reviews could drop from ~50 → ~17 per 100 roofs, keeping a person on every hard call

What if we do nothing?

  • Every ambiguous roof keeps costing a full manual review
  • The scanner's error rate on complex roofs stays unmeasured
  • No ground-truth data accumulates for future improvement

What could go wrong

  • Escalation recall stays low → rubber-stamps wrong answers
  • Escalation explodes → no savings, added noise
  • Imagery domain shift → needs NYC calibration set
  • Missing/bad inputs untested — PRD §5 abstain rules defined, testing part of limited test

What we'd ask Con Edison

  • Which error has historically cost more — false solar or false no-solar?
  • What context data (footprints, permits, historical imagery) is shareable?
  • How should results return to your review tooling?

SolarScan Verify: the scanner stays; the ambiguous roofs get a second, explainable, human-escalated look.
