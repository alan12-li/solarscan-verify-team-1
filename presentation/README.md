The capstone requires the presentation to be **committed to the team
repository as an HTML page**. Put the final HTML here, e.g.:

```
presentation/index.html
```

Guidelines:

  offline).
- Public/synthetic evidence only — no Con Edison operational data.

  results, one failed approach + one promising approach with evidence.
- Keep a `NOTES.md` beside it for speaker notes and the decision owner.
