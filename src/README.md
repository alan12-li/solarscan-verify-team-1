# src/

Prototype source code for SolarScan Verify.

Per the course sims convention (`sims/README.md`), the sim's source code lives
in a `src/` subfolder of the sim folder in the **course repository**
(`sims/solarscan-verify/src/`). This `src/` folder in the team repository is
for working prototypes and experiments before they are ready to ship as a
course PR.

Convention:
- One folder per prototype/experiment (e.g. `src/proto-v1-classifier/`).
- Keep a short `README.md` per prototype: what it does, model IDs used, how
  to run, and what evidence it produced.
- Preserve informative failures — a failed approach with its evidence is a
  capstone deliverable.
